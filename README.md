# 🏢 نظام مُحصّل لإدارة العقارات والتحصيل والمحاسبة المالية
### Mouhassil Property Financial Suite

> تصميم م. أبو أحمد — مصمم ومنفذ Claude — © الحقوق محفوظة

نظام متكامل لإدارة العقارات والعقود والمستأجرين، الفواتير وسندات القبض والصرف، المحاسبة بالقيد المزدوج، الأصول الثابتة والإهلاك، الشواغر، الصلاحيات المتعددة، النسخ الاحتياطي، وتصدير Excel/PDF.

---

## 🚀 التشغيل

المتطلبات: Node.js 20 فما فوق، و npm.

```bash
npm install
npm run dev          # وضع التطوير  → http://localhost:3000
```

الإنتاج:
```bash
npm run build        # يبني الواجهة + خادم dist/server.js
npm start            # يشغّل النظام (المنفذ من PORT، الافتراضي 3000)
```

الفحص الكامل:
```bash
npm run test:all     # tsc + اختبارات المنطق (29) + اختبارات الـ API (23)
```

## ⚙️ متغيرات البيئة (انسخ `.env.example` إلى `.env`)

| المتغير | الوظيفة |
|---|---|
| `PORT` | منفذ الخادم (الافتراضي 3000) |
| `ADMIN_INITIAL_PASSWORD` | كلمة مرور المدير العام عند أول تشغيل (8 أحرف فأكثر). إن لم تُحدَّد تُولَّد كلمة عشوائية |
| `MUHASSIL_DATA_DIR` | مجلد حفظ البيانات. **في الاستضافة وجّهه إلى قرص دائم (Volume)** وإلا ضاعت البيانات عند إعادة النشر |
| `SESSION_SECRET` | (اختياري) سرّ توقيع رموز الجلسات |
| `GEMINI_API_KEY` وإعدادات Firebase | اختيارية |

## 🔑 الدخول لأول مرة

- بريد المدير العام: `mouhassil.demo@gmail.com`
- كلمة المرور: قيمة `ADMIN_INITIAL_PASSWORD`، أو الكلمة العشوائية المكتوبة في `data/FIRST_RUN_ADMIN_PASSWORD.txt` (وتظهر مرة واحدة في سجل الخادم).
- يُطلب تغيير كلمة المرور فور أول دخول، وتُحذف ملف الكلمة الأولى تلقائيًا بعد التغيير.
- كلمات المرور محفوظة مُشفّرة (scrypt) ولا تُرسل إلى المتصفح أبدًا.
- الموظفون الجدد يحصلون على كلمة مؤقتة يغيّرونها عند أول دخول (8 أحرف على الأقل).

## ✨ ما تم تحسينه في هذه النسخة

- **الشواغر:** حالة الوحدة تُشتق تلقائيًا من العقود النشطة (مصدر واحد للحقيقة)، منع تداخل العقود على الوحدة، زر «إنهاء وإخلاء» للعقد، ولوحة شواغر تعرض نسبة الشغور والخسارة الشهرية المقدّرة ومدة الشغور.
- **الأصول الثابتة:** تبويب جديد يقبل المباني والأراضي والمولدات والمعدات والأثاث والمركبات وغيرها، مع قيد اقتناء متوازن (نقد/بنك/دائنون/رأس مال) وإهلاك شهري بالقسط الثابت (الأرض لا تُهلك)، ومجمع الإهلاك يظهر سالبًا في الميزانية.
- **الأمان:** تشفير كلمات المرور، إزالة كلمات المرور المضمّنة في الكود، تحقق الخادم من كلمة المرور الحالية عند التغيير، وعدم تسريبها عبر `/api/state` أو البث الحي.
- **الأداء:** تحميل كسول للشاشات الثقيلة، وحفظ مؤجَّل وذري للبيانات على الخادم.
